**在线地址（合并后）：** https://WRM-FW.github.io/apex-atlas/

## 发布流程

本仓库启用了「人工审核后发布」：

1. 所有改动走 Pull Request；
2. `main` 分支受保护，必须有 1 个 approve 才能合并；
3. 合并进 `main` 之后，GitHub Actions 才构建并正式发布；
4. PR 打开时 Actions 会生成一个临时预览地址，供审核时查看效果。

详见待合并 PR 中的 README（含目录结构、本地预览、数据维护说明）。
